# STICKMAN CO-OP — сервер на ноутбуке

**Постоянная ссылка (GitHub Pages):** https://formahedon51.github.io/stickman-coop/

Локальный сервер, который:

1. раздаёт саму игру (`public/`);
2. поднимает **PeerJS signaling** на `/peerjs` — через него игроки находят друг друга;
3. показывает адрес в локальной сети и отдаёт ссылку-приглашение `?room=КОД`.

Сам игровой трафик идёт **напрямую между браузерами (WebRTC P2P)**. Сервер только сводит игроков.

## Постоянная ссылка (GitHub Pages)

Игра статическая, поэтому её можно бесплатно держать на GitHub Pages:

```
https://formahedon51.github.io/stickman-coop/
```

Это **постоянная ссылка**, не зависящая от туннеля и ноутбука. На Pages игра использует **публичный PeerJS** для сигналинга (Node-сервер на Pages работать не может). Локальный сервер ниже остаётся для игры через свой ноутбук.

Включение:

1. Запушь репозиторий в ветку `main`.
2. Workflow уже лежит в `.github/workflows/pages.yml` и запустится сам.
3. В GitHub: **Settings → Pages → Source: GitHub Actions**.
4. Через минуту игра будет по адресу `https://formahedon51.github.io/stickman-coop/`.

Если нужна постоянная **серверная** ссылка (свой signaling на ноутбуке), используй именованный Cloudflare Tunnel с доменом или задеплой `server.js` на Render/Fly/Railway.

### Как Pages использует сервер ноутбука

При старте `start.sh` публикует текущий адрес туннеля в `public/servers.json` и пушит его в GitHub. Pages-версия при загрузке читает `servers.json` и использует signaling с ноутбука **первым**; публичный PeerJS — запасной вариант. Поэтому после запуска ноутбука подожди ~30 секунд (передеплой Pages) и обнови страницу.

Если ноутбук выключен, ссылка продолжит работать через публичный PeerJS (если он доступен в сети игрока).

### Если пишет «Все серверы не отвечают»

- Откройте ссылку в **Chrome или Safari**, а не во встроенном браузере VK/Telegram/Instagram — они часто блокируют WebSocket/WebRTC.
- Включите VPN, если публичный PeerJS недоступен.
- Убедитесь, что ноутбук с сервером включён и туннель поднят (`./start.sh`).

## Установка (один раз)

```bash
cd "/home/formahedon51/Документы/Проект по умолчанию/stickman-coop"
./install.sh
```

Скрипт ставит зависимости и cloudflared, добавляет **автозапуск сервера при входе в систему** и **не создаёт иконки на рабочем столе** (ранее созданные удаляет).

## Запуск

Сервер и публичный туннель стартуют автоматически при входе в систему. Открыть игру:

- в браузере: `http://localhost:9000/`;
- или в меню приложений: **STICKMAN CO-OP**.

Публичная ссылка для друзей появляется в лобби после создания комнаты. Туннель поднимается ~20–30 секунд, ссылка обновится сама (страница опрашивает статус каждые 10 секунд).

## Отключить автозапуск

```bash
rm ~/.config/autostart/stickman-coop.desktop
```

Остановить сервер сейчас: `./stop.sh` или пункт меню **STICKMAN CO-OP — стоп**.

## Игра вдвоём в одной Wi-Fi

1. Хост нажимает **«Создать комнату»**.
2. В лобби появляются код и ссылка вида `http://192.168.1.159:9000/?room=XXXXXX`.
3. Нажми **«Копировать ссылку»** и отправь другу.
4. Друг открывает ссылку — код уже подставлен, остаётся нажать **«Войти по коду»**.

> Хост может играть и через `localhost`, но ссылку гостю нужно давать с IP ноутбука в Wi-Fi (`192.168.x.x`) — она и показывается в лобби.

## Игра через интернет (автоматически)

Иконка **STICKMAN CO-OP** теперь сама поднимает публичный туннель через **cloudflared** (бесплатно, без аккаунта) и открывает игру по HTTPS-ссылке вида:

```
https://random-words-1234.trycloudflare.com/
```

Эту ссылку видно:

- в терминале/логе запуска;
- в самой игре в меню («Сервер этого ноутбука: …»);
- в лобби — кнопка **«Копировать ссылку»** (уже вместе с кодом комнаты).

Друг из любой точки мира открывает ссылку в браузере, вводит код (или получает ссылку с `?room=КОД`) и играет.

### Важно

- Публичный адрес **меняется при каждом запуске** туннеля — отправляй другу свежую ссылку из лобби.
- Порт 9000 наружу открывать **не нужно**: cloudflared сам делает исходящее соединение. Ноутбук остаётся за NAT.
- Quick Tunnel бесплатен, но без гарантий аптайма. Для постоянной ссылки нужен именованный туннель Cloudflare (аккаунт + домен) или Tailscale.
- Если провайдер/сеть блокирует Cloudflare, используй альтернативу: `ngrok http 9000`, `ssh -R 80:localhost:9000 nokey@localhost.run`, либо Tailscale/ZeroTier.
- Только локальная сеть (без туннеля): `TUNNEL=0 ./start.sh`.

### Свой TURN (если P2P не пробивается)

WebRTC может не соединиться за строгим NAT. В игре уже прописан публичный TURN (OpenRelay), но для стабильной игры через интернет лучше поднять свой `coturn` и указать его в `public/index.html` в `ICE_SERVERS`.

Пункт меню **STICKMAN CO-OP — стоп** или:

```bash
./stop.sh
```

## Порт

По умолчанию **9000**. Другой порт:

```bash
PORT=9001 ./start.sh
```

Иконка на рабочем столе запускает с портом 9000.

## Проверка

- `http://localhost:9000/healthz` → `ok`
- `http://localhost:9000/api/status` → JSON с IP, портом и числом онлайн-клиентов

## Безопасность

Сервер не хранит данные и не пропускает игровой трафик через себя. Но любой, кто знает адрес и порт, может создавать комнаты. Не открывай порт в интернет без необходимости — для игры с друзьями лучше VPN или туннель.

## Что внутри

```
stickman-coop/
├── server.js              # Express + PeerJS signaling + статика
├── start.sh / stop.sh     # запуск/остановка
├── autostart.sh           # автозапуск при входе в систему
├── install.sh             # установка, cloudflared, автозапуск
├── public/
│   ├── index.html         # игра (V2)
│   ├── icon.svg           # иконка
│   └── vendor/peerjs.min.js
├── logs/server.log
└── README.md
```

Игра не зависит от CDN: `peerjs.min.js` лежит локально, поэтому работает и без интернета (в локальной сети).
